# MUKISS: Web-Based Product Information and Flavor Catalog System

## Project Overview

MUKISS is a web-based educational prototype developed as a school project. 
The system demonstrates how product information, flavor profiles, specifications, 
user accounts, and customer inquiries can be organized in a modern web interface.

The website uses fictional/sample product information and does not process real product sales or transactions.

## Objectives

- Develop a responsive and user-friendly website.
- Display organized product and flavor information.
- Provide searchable product information.
- Implement user registration and account verification.
- Implement login and session management.
- Store information using PHP and MySQL.
- Demonstrate frontend and backend web development.

## Main Features

- Age verification
- User registration
- Account verification
- User login and logout
- User account page
- Flavor catalog
- Product search
- Product specifications
- Product images
- About page
- Contact and inquiry form
- Responsive navigation

## Database

The system uses MySQL to store:

- User accounts
- Products
- Flavor information
- Inventory/sample data
- Customer inquiries
- Verification codes

Sensitive database credentials are not included in this repository.
