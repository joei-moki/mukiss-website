Introduction to HTML

HTML stands for HyperText Markup Language. It is used to create and organize the content of web pages.

HTML uses elements called tags to tell the browser how different parts of a webpage should be displayed.

Tip: HTML is one of the basic technologies used in web development.

Basic HTML Structure

A basic HTML document usually contains the following structure: 

<!DOCTYPE html>
<html>

<head>
    <title>My Web Page</title>
</head>

<body>

    <h1>Hello World!</h1>

    <p>
        This is my first web page.
    </p>

</body>

</html>

Common HTML Elements

Here are some common HTML elements:

  • <h1> — creates a main heading
  • <p> — creates a paragraph
  • <a> — creates a link
  • <img> — displays an image
  • <button> — creates a button

Simple HTML Example

The following example creates a heading, paragraph, and link: 

<h1>Welcome to My Website</h1>

<p>
    This is a simple HTML paragraph.
</p>

<a href="https://example.com">
    Visit Website
</a>
