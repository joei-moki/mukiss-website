Introduction to HTML

HTML stands for HyperText Markup Language. It is used to create and organize the content of web pages.

HTML uses elements called tags to tell the browser how different pieces of content should be displayed.

Basic HTML Structure

A basic HTML document usually contains the following structure: 

<!DOCTYPE html>
<html>

<head>
    <title>My Web Page</title>
</head>

<body>

    <h1>Hello World!</h1>

    <p>This is my first web page.</p>

</body>

</html>

Common HTML Elements

Some common HTML elements include:

  • <h1> - creates a main heading
  • <p> - creates a paragraph
  • <a> - creates a link
  • <img> - displays an image
  • <button> - creates a button
